# 记一下（原拾页 / 有序）

随手记下想法，按日回看生活的本地记录工具。Android，Kotlin + Compose，数据只存本机。

> **许可证**：MIT，见 [LICENSE](LICENSE)。
> **状态**：可自行编译使用，但尚未完整验收。已知问题见 [Issues](https://github.com/h516df/jiyixia/issues)——
> 主要是正式签名密钥的备份、系统云备份开关与「数据只在这台手机」不一致、以及换机迁移路径。
> 自行编译时请用自己的签名密钥，不要沿用本仓库的更新与签名配置。

- 随手记录：无需标题和分类，底部直接输入，保存后进入正文时间流。草稿本地保留，写盘失败不清空。
- 首页直接开始短录音或长录音，也能快速添加照片、视频；录音由麦克风前台服务保持，锁屏或切换应用后仍可继续，通过通知栏暂停、继续或结束。Android 13+ 若拒绝通知权限，仍可录音，但需回应用内操作。约每 30 秒保存已完成音频片段，一次录音合为一条语音记录，结束后自动入库；保存失败时保留草稿和原音频。强杀时正在录制的片段可能无法恢复，完成片段优先保留。
- 全屏编辑器继续支持本地录音、照片与视频，可保存只有媒体的记录；旧版编辑器内录音依然在离页时暂停，不与新的持续录音同时占用麦克风。所有媒体仍留在本机私有目录。旧媒体设计边界见 [媒体设计说明](docs/design/voice-media.md)。
- 中文 #标签、全文搜索、归档恢复和手动翻看旧记录。
- 日记：独立记录一天的感受与小结，支持选择日期、补记与同日多篇。当天碎片作为可折叠参考直接展开，不自动复制成日记。
- 系统文字分享先进入草稿，保存后才写入；新分享不会静默覆盖正在编辑的文字。
- 旧版事项已从日常界面移除。原文、来源、日期、状态、步骤和办理过程保留在“设置 → 旧版资料”，仅供阅读。
- 本地导入预览：Obsidian Markdown/vault ZIP、Thino DAILY 时间片段、Diarium JSON/附件 ZIP，以及墨记 PDF/图片原件收存。格式范围与限制见 [导入说明](docs/design/import-formats.md)。
- “设置 → 导出完整资料”生成包含全部记录、旧资料与附件的 ZIP，可在“导入记录 → 记一下完整备份”恢复缺少的内容。冲突保留现有记录；损坏或超限明确失败。完整备份流式读写，附件上限 1 GiB、解压总计 4 GiB、5000 条记录；其它来源导入仍保持原有 32/64 MiB 限制。

## 数据与更新

继续使用原来的本地 tasks.json 和备份文件。旧版拾页完整 ZIP 继续兼容，内部 shiye-backup 格式标识、cn.jiaoban 应用 ID、私有目录和签名验证路径均不随名称改变。新日记为 NOTE 加可选 journalDate，旧笔记/旧事项不批量迁移。不要卸载、清除资料或降级；旧版本保存时可能丢掉新增日期字段。

仓库地址 h516df/jiyixia（固定仓库 ID 1413866214）。应用 ID cn.jiaoban、原签名验证链路和安装包资产前缀保持原样。默认检查固定公开稳定清单，免登录，不读取全仓 latest；下载和安装前核对大小、SHA256、包名、版本、架构与原证书。进入应用不自动联网下载，系统安装仍由用户确认。正式包直接覆盖安装，不卸载或清除资料；云端 unsigned/debug 包不能作为正式升级包。

## 开发验证

JDK 21、Android SDK 36、Gradle 9.1、Kotlin/Compose，使用官方 Media3 播放本地音视频。单测覆盖原有数据兼容；WritingUiTest 使用 Robolectric + Roborazzi 检查实际 Compose 交互与渲染。所有测试仅用合成记录，不能在用户手机执行会改数据的验收探针。

参考与设计取舍见 [设计说明](docs/design/shiye-20261019.md)。历史验收见 [0.17 验收](docs/acceptance/v0.17/README.md)，0.21 候选的功能与尚待手机验证的边界见 [更新记录](CHANGELOG.md)。正式安装包以 [发布页](https://github.com/h516df/jiyixia/releases) 为准，发布不代表用户设备已升级。你手机上的 0.19 只能用原签名、递增版本号的正式 APK 直接覆盖升级；不要卸载、清数据或改用云端调试 APK。
