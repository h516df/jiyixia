# 交办

**下载安装包**：[最新发布版](https://github.com/h516df/Jiaoban/releases/latest) 里的 `Jiaoban-v<版本>-universal.apk`。手机上下载后点开，允许一次"未知来源"即可安装。

记录领导或别人交代的事。每件事自带有效期：**有效期内它在你眼前，过期它自己退场，但不删，随时能翻回来。**

它不是待办清单，也不是笔记：

- 待办按「我要做什么」组织，做完才算完，没做完一直挂着
- 这个本子按「谁交代的、什么时候的事」组织，你不需要"完成"它，只需要它在有效期内别被忘掉
- 笔记存进去就再也不出来

## 怎么用

打开就是首页，底部一行输入框，光标已经在里面。打一句话，点「记下」（或按键盘完成键）：

```
王总说明天要周报
```

它自己认出来：**事**＝要周报，**谁**＝王总，**期限**＝明天。一个字都不用多填。

- 认不出的部分：没提期限就默认给 3 天寿命
- 认错了：点开那一条就能改人和期限
- 不想打字：微信里长按消息 → 分享 → 交办，一样认人认期限

## 现在能做什么

- **一句话记一条**：不选分类、不打标签、不想标题
- **自动认期限**：今天 / 明天 / 后天 / 大后天 / 周X / 这周五 / 下周三 / 月底 / 周末 / N号 / N月N日 / N天后 / 一周后 / 半个月后 / 2个月后
- **自动认人**：「说 / 让 / 要 / 叫 / 催 / 要求」前面的名字，加上你最近记过的人名
- **流水式主列表**：最近记的在最上面；「今天要交的」单独拎到最上面
- **过期自动退场**：不再占主流水，折进底部「已过期 N 件」，点开才看
- **勾一下算办完**：办完和作废的都进「历史」，随时能恢复（作废不是删除）
- **全局搜索**：过期、办完、作废的都能按事或按人翻出来
- **记录在本地保存**：`files/tasks.json`，写的时候先写临时文件再改名，旧版本留一份 `.bak`

## 技术

- Kotlin + Jetpack Compose（Material 3），AGP 9.0.1 / Kotlin 2.3.20 / compileSdk 36 / minSdk 26
- **没有任何第三方运行时依赖**，中文期限解析是自己写的规则（见 `app/src/main/java/cn/jiaoban/parse/DueParser.kt`）
- 业务逻辑（认期限、认人、分档、排序、搜索、编解码、存取）全部有 JVM 单测
- 正式版开了 R8 压缩：APK 从 12 MB 降到约 1.7 MB

关于中文时间解析库：试过 GitHub 上那个 Java 的 `xk-time`（Time-NLP 改良版，Apache-2.0），**它在安卓上跑不起来**。
它的预编译正则表是 JDK 序列化的 `java.util.regex.Pattern`，安卓读不了；退回自己编译时又撞上安卓正则不接受
`{0,1}\d+` 这种写法，每次解析都抛 `PatternSyntaxException`。所以改成自己写规则，全部单测覆盖。

## 构建与验收

```powershell
# 单测 + 出包
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:assembleRelease

# 专用模拟器 UI 回归：会替换测试种子记录，不可用于用户手机
$env:JIAOBAN_ADB_PORT = "5041"
python -X utf8 scripts\android_acceptance.py --serial 127.0.0.1:5581

# 正式版冒烟：调试版/正式版帧数据对比 + 覆盖安装不丢数据 + 压缩后解析仍可用
python -X utf8 scripts\release_smoke.py
```

截图和界面 dump 落在 `verification\`，脚本最后给出逐项 PASS/FAIL 汇总，任一项失败退出码非 0。

## 本轮修复（0.8 候选）

- 取消更新授权后可以再次检查，无需重启 App。
- 长分享保存全部文字，末尾期限和 emoji 不再被截断。
- 后台过夜回来以及前台日期变化，主页和其他页面及时刷新日期。
- 过期区展开滚动使用实际位置，展开内容能翻到。

## 已知限制

- 尚无导出/恢复入口；系统备份与换机策略仍待确认（Issue #3、#5），同目录 `.bak` 不能替代独立备份。
- 只做安卓端；电脑端、跨设备同步、提醒推送都没做
- 期限只认到"哪一天"，不认具体几点（记的是有效期，不是日程）
- 期限和人名是规则认的，会认错，认错点开改（比每次手填省事）
- 没有物理删除，作废就是最终形态（故意的，留反悔余地）
- 打开就自动弹键盘（为了"打开就能打字"）；嫌吵可以改成点了才弹
