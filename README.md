# 拾页（原有序）

随手记下想法，按日回看生活的本地文字工具。

- 随手记录：无需标题和分类，底部直接输入，保存后进入正文时间流。草稿本地保留，写盘失败不清空。
- 中文 #标签、全文搜索、归档恢复和手动翻看旧记录。
- 日记：独立记录一天的感受与小结，支持选择日期、补记与同日多篇。当天碎片仅在折叠参考中查看，不自动复制成日记。
- 系统文字分享先进入草稿，保存后才写入；新分享不会静默覆盖正在编辑的文字。
- 旧版事项已从日常界面移除。原文、来源、日期、状态、步骤和办理过程保留在“设置 → 旧版资料”，仅供阅读。
- 本地导入预览：Obsidian Markdown/vault ZIP、Thino DAILY 时间片段、Diarium JSON/附件 ZIP，以及墨记 PDF/图片原件收存。格式范围与限制见 [导入说明](docs/design/import-formats.md)。
- “设置 → 导出完整资料”生成包含全部记录、旧资料与附件的 ZIP，可在“导入记录 → 拾页完整备份”恢复缺少的内容。冲突保留现有记录；损坏或超限明确失败。

## 数据与更新

继续使用原来的本地 tasks.json 和备份文件。新日记为 NOTE 加可选 journalDate，旧笔记/旧事项不批量迁移。不要卸载、清除资料或降级；旧版本保存时可能丢掉新增日期字段。

应用 ID cn.jiaoban、私有更新仓库和签名验证链路不变。正式更新必须用原证书签名后覆盖安装；云端 debug 测试包不是正式升级包。

## 开发验证

JDK 21、Android SDK 36、Gradle 9.1、Kotlin/Compose，未增加运行时依赖。单测覆盖原有数据兼容；WritingUiTest 使用 Robolectric + Roborazzi 检查实际 Compose 交互与渲染。所有测试仅用合成记录，不能在用户手机执行会改数据的验收探针。
