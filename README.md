# 交办

**下载安装包**：[最新发布版](https://github.com/h516df/Jiaoban/releases/latest) 里的 `app-debug.apk`。手机上下载后点开，允许一次"未知来源"即可安装。

记录领导或别人交代的事。有的事过一段时间就没用了，所以**到期没办的会自己沉到底下**，
不用你手动删、不用整理、不用分类。

安卓端先做，其他端先不考虑。

## 现在能做什么

- **三秒记一条**：什么事、谁交代的、什么时候要（默认三天后）
- **主列表只摆活的事**：今天 / 明天 / 这周 / 以后 / 没定期限，按急迫程度排
- **到期自动沉底**：过了期没办的事不再占主列表，折在底部「已过期 N 件」里，点开才看
- **划掉就是办完**：右侧勾一下即可，也可以点开改期限、作废、恢复
- **作废不是删除**：办完和作废的都进「历史」，随时能恢复
- **搜索是全局的**：过期、办完、作废的都能按事或按人翻出来
- **数据只在这台手机上**：`files/tasks.json`，写的时候先写临时文件再改名，旧版本留一份 `.bak`

## 技术

- Kotlin + Jetpack Compose（Material 3），AGP 9.0.1 / Kotlin 2.3.20 / compileSdk 36 / minSdk 26
- 无第三方运行时依赖，JSON 手写编解码（`org.json` 随系统）
- 业务逻辑（分档、排序、搜索、编解码、存取）全部有 JVM 单测

## 构建与验收

```powershell
# 单测 + 出包
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug

# 真机（模拟器）验收：装包 -> 塞入记录 -> 走真实路径 -> 截图
python -X utf8 scripts\android_acceptance.py
```

验收截图落在 `verification\`，控制台最后给出逐项 PASS/FAIL 汇总，任一项失败退出码非 0。

## 已知限制

- 只做安卓端；电脑端、跨设备同步、提醒推送都没做
- 期限只能从「今天 / 明天 / 三天后 / 一周后 / 没期限」里选，没有任意日期选择器
- 没有物理删除，作废就是最终形态（这是故意的，留反悔余地）
