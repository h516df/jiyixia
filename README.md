# 记一下（原拾页 / 有序）

随手记下想法，按日回看生活的本地记录工具。

- 随手记录：无需标题和分类，底部直接输入，保存后进入正文时间流。草稿本地保留，写盘失败不清空。
- 编辑器支持本机录音、照片与视频，也能保存只有媒体的记录；原媒体复制到私有目录，草稿保留附件引用。录音只在前台页面进行，离开/锁屏暂停；完成片段可恢复，不承诺强杀时正在录制的片段零丢失。详见 [媒体设计与边界](docs/design/voice-media.md)。
- 中文 #标签、全文搜索、归档恢复和手动翻看旧记录。
- 日记：独立记录一天的感受与小结，支持选择日期、补记与同日多篇。当天碎片仅在折叠参考中查看，不自动复制成日记。
- 系统文字分享先进入草稿，保存后才写入；新分享不会静默覆盖正在编辑的文字。
- 旧版事项已从日常界面移除。原文、来源、日期、状态、步骤和办理过程保留在“设置 → 旧版资料”，仅供阅读。
- 本地导入预览：Obsidian Markdown/vault ZIP、Thino DAILY 时间片段、Diarium JSON/附件 ZIP，以及墨记 PDF/图片原件收存。格式范围与限制见 [导入说明](docs/design/import-formats.md)。
- “设置 → 导出完整资料”生成包含全部记录、旧资料与附件的 ZIP，可在“导入记录 → 记一下完整备份”恢复缺少的内容。冲突保留现有记录；损坏或超限明确失败。完整备份流式读写，附件上限 1 GiB、解压总计 4 GiB、5000 条记录；其它来源导入仍保持原有 32/64 MiB 限制。

## 数据与更新

继续使用原来的本地 tasks.json 和备份文件。旧版拾页完整 ZIP 继续兼容，内部 shiye-backup 格式标识、cn.jiaoban 应用 ID、私有目录和签名验证路径均不随名称改变。新日记为 NOTE 加可选 journalDate，旧笔记/旧事项不批量迁移。不要卸载、清除资料或降级；旧版本保存时可能丢掉新增日期字段。

私有仓库已改名为 h516df/jiyixia（固定仓库 ID 1413866214），更新白名单与授权页名称同步。应用 ID cn.jiaoban、原签名验证链路和 Jiaoban 安装包资产前缀不变。正式更新必须用原证书签名后覆盖安装；云端 debug 测试包不是正式升级包。应用内更新会在下载和安装前校验文件、包名、版本与签名；进入应用只恢复本机状态，不自动联网下载。系统安装仍由用户确认。
