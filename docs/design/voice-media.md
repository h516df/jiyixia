# 记一下本机录音与照片视频

基线：main cc049eedd（0.17）。不合入独立的旧记录回顾候选，当前品牌改为“记一下”，已验证仓库迁移至 h516df/jiyixia（同仓库 ID 1413866214），保留旧版拾页备份兼容；不改变应用 ID、原签名或既有记录格式。

## 第一版范围

- 编辑器提供“录音”“照片 / 视频”，允许只有媒体的记录或日记；正文、日期和附件引用保留在本机草稿。照片、视频选择使用 Android Photo Picker（旧系统由 Activity 合约回退）；不申请整个相册、存储或电话权限。
- 点击录音才申请 RECORD_AUDIO；MediaRecorder 保存 AAC/M4A 原始录音。暂停/结束完成当前片段，继续录音明确由用户点击。每约 30 秒完成一个片段，因此界面可能出现多个录音附件，边界有短暂间隔，不宣称连续无缝。
- 仅前台编辑页录音。离开应用、锁屏或编辑页销毁时停止麦克风并保留完成片段；通话模式、API29+ 输入静音回调和权限撤回会中断，不自动恢复麦克风。没有麦克风前台服务，不宣称后台/锁屏持续录音。
- M4A 需要停止后完成封装。崩溃/强杀/断电时活动片段可能不可播放或丢失；已完成片段通过 fsync 后重命名留在本机 journal，下次打开对应草稿可恢复。附件引用成功落盘后才写送达回执，防止主动移除的附件重建时重新出现。未完成原件不自动删除，不承诺零丢失。
- 选择媒体后把 provider 提供的原字节以固定缓冲区复制、SHA-256 校验、fsync、原子不可覆盖发布至私有 imports；不压缩/转码，不以短期 URI 作为永久资料。移除附件只移除该页引用，不自动删除源文件。预览照片采用受限解码，音视频使用官方 Media3，点击后播放，退出页面/后台停止，不上传或转写。
- 完整备份兼容 v1 格式，但使用流式复制与私有缓存暂存恢复，不再把整个视频读入 ByteArray。上限 1 GiB/附件、4 GiB 解压总量、32 MiB/元数据文件、5000 条记录、10000 个 ZIP 条目；超限或磁盘不足明确失败。旧 Obsidian/Thino/Diarium/墨记导入限制保持 32/64 MiB，不扩大未验证解析范围。
- 完整备份涵盖已保存记录及其引用附件；未保存草稿和未完成录音不是完整备份记录。卸载或清除资料仍会丢失本机数据。恢复先预览，确认后合并，冲突/损坏现存附件不覆盖。

## 选择依据

- [Android Photo Picker](https://developer.android.com/training/data-storage/shared/photo-picker)：仅用户选中的媒体，无需读整个相册；已有 Activity Compose 依赖支持合约。
- [Android MediaRecorder](https://developer.android.com/media/platform/mediarecorder)：原生录音、可检查活动录音配置；使用分段完成文件避免把未封装的活动文件误报成可恢复内容。
- [共享音频输入](https://developer.android.com/media/platform/sharing-audio-input)：其他应用或系统可能使录音输入静音，不能只检查权限。
- [Media3 / ExoPlayer](https://developer.android.com/media/media3/exoplayer)：官方维护的本地音视频播放组件。依赖 Media3 1.9.3，Apache-2.0；没有复制第三方业务代码。

## 仍需设备验收

真实麦克风录音与听回、快速暂停/继续/结束、真实来电和其他音频占用、系统撤回权限、锁屏/返回桌面、系统 Photo Picker 与旧系统回退、删除相册源文件后的播放、视频格式兼容、低存储、超大文件、进程杀死后的已完成片段恢复。云端单测和合成 Compose 图不能替代这些测试；不在用户实际资料上运行重置探针。不签名、不发布、不升级手机。
