# v0.24｜整体体验完善：苹果式视觉与交互方案

> 状态：**设计方向已选定，未开发、未验收**。讨论整理日期：2026-11-01（Asia/Shanghai）。  
> 现场基线：`main` `91525ac67a4c872b7a005bcbfce97adf2fb9e9c7`；最新正式 Release 为 `v0.23`。开发前重新核对最新 main、PR 和发行状态。  
> 这是开发交接规格，不是准许提前发布 APK。效果图仅作视觉方向参考，不等于已验收的像素稿。

## 1. 目标与已确认偏好

选择方案 A：以 **整体体验完善** 为 v0.24 主线，不增加账号、云端依赖或大而全新模块。

- 视觉方向：苹果 Notes / Journal 的精致层级，参考 iOS 26 的轻量 Liquid Glass **导航材质**；Android 保留自身返回手势、输入法、系统媒体选择器和权限习惯。用户已认可最新整体方向，但认为此前几个设计过于简陋或字太多，细节仍须真实渲染后定。
- 字少、信息密度合理；页面主体是实际文字、图片、视频、录音，而不是装饰说明。去掉冗余标题、辅助文案、重复导航、大块空白和臃肿卡片。
- **记录/日记一致**：同一套中性浅色/暗色、清晰中文无衬线、少量暖琥珀强调色；照片自然带来彩色。毛玻璃只用于底部浮动操作层，避免处处玻璃、持续昂贵模糊。
- **左滑直接删除**：在列表条目内部向左划出足够距离并松手，立即移入回收站；**不露出一个还要再次点击的红色“删除”按钮**。不足阈值回弹，短促触感反馈，底部显示可点击的“撤销”；不劫持 Android 边缘返回手势。
- 目标是成熟 Android App，不是 iOS 截图复刻，也不是只有静态美术的 demo。

## 2. 页面与内容结构

### 记录首页

- 顶部页名简洁；默认按日期显示时间流。文字记录用紧凑分组与细分隔线；有图片的记录才显示缩略图/适当比例预览，**不强迫每条记录变大卡片**；录音直接显示播放入口和时长。
- 底部使用节制的浮动操作层：`记录 / 日记`、搜索、主写入入口。随着滚动自然收敛，输入时退场，任何时候不遮挡最后一条内容或系统导航栏。
- 点条目进入阅读，返回保留滚动位置。长按可提供复制、分享、置顶等次级操作；不用把所有操作铺在条目上。
- 主写入入口 **一次点击即可进入正文和键盘**；不强制填写标题、分类、标签。

### 日记

- 与首页共用视觉 token、图标、底部浮动操作，但内容表现更沉浸：紧凑的周日期条，点日期切换；左右划动周条切换周，不挤压正文。
- 日记支持自然段落与图文混排；当天随记/录音自动聚合为可收起内容。不要求每次先创建日记、再选分类，不改写旧日记数据的含义。
- 纯文字日期不生成空照片框；无记录日不过度解释。长篇可连续阅读，不能每个换行都空一大块。

### 编辑 / 阅读

- 全屏编辑器：正文直接输入，不强制标题；上方轻量日期和“完成”，下方键盘上沿只露出图片/视频/录音/附件等真正有用的操作。
- 草稿需自动持久保存：后台切换、系统返回、键盘收起、附件选择往返后不丢文字；“完成”负责结束编辑。空白退出不制造空记录；真正存储失败要明确反馈和可重试，不能虚报保存成功。
- 字体建议正文约 16–18sp、行高约 1.45–1.6、段间距约 8–12dp；动态字号按系统缩放。跨自然段可连续选择/复制，长按菜单不阻断滚动。
- **当前确定的排版缺陷**：`app/src/main/java/cn/jiaoban/ui/Notes.kt` 中 `NoteDetail` 使用 `note.text.split('\\n')` 为每行创建独立 LazyColumn item，父列 `Arrangement.spacedBy(18.dp)`，导致每个换行出现巨大额外距离、跨行选择不自然。v0.24 应把正文视为连续文本块并保留旧换行语义、检查旧清单格式兼容。

### 搜索 / 图片视频 / 录音

- 搜索图标点击后展开输入框并自动聚焦，离线实时筛选；复用现有搜索能力和筛选，不造复杂新搜索服务。关闭后恢复原列表与位置。
- 图片点击全屏，支持横向查看与双指缩放；视频沿用系统/Media3 成熟能力；回退和媒体缺失状态清晰而少字。
- 录音列表内可播；开始/暂停/继续/结束及失败恢复始终有清晰状态。保留当前前台服务、锁屏录制和分段/恢复能力，不因视觉改造重写底层或误删录音源文件。
- 不用繁琐“操作成功”弹窗；成功通过自然状态变化表达，失败和不可逆风险才强调。

## 3. 交互与动态准则

| 场景 | 预期行为 |
| --- | --- |
| 左滑记录/日记 | 手指跟随，达到阈值松手软删除；不足阈值回弹；不出现二次点击的删除按钮 |
| 删除后 | 轻触感 + 列表收拢 + 底部“已删除 · 撤销”；回收站可恢复，30 天规则保持 |
| 写入 | 点写入即定位光标、键盘打开；自动暂存；完成/返回不丢草稿 |
| 键盘出现/消失 | 内容、工具栏、导航跟随 IME 平滑布局，不突然整块跳动或压住光标 |
| 搜索 | 搜索按钮平滑转成输入状态，边打边显示结果，退出恢复位置 |
| 切日期/切页 | 轻量连续过渡，状态和滚动位置合理保留，不为动画牺牲响应 |
| 图片/录音 | 原位可预览/播放，必要时进沉浸查看，不反复跳转 |

- 动效轻、短、跟手；滚动与滑动应可被系统“减少动画”设置弱化。振动只用在完成、阈值、录音关键状态，不做连续震动。
- 交互应兼顾屏幕阅读器、触控目标、窄屏及大字，提供不依赖滑动的替代删除入口（例如长按操作），但不在默认界面堆文字。
- “苹果式”不等于照抄 iOS 键盘、系统返回、权限面板；优先复用 Kotlin Compose/Android 系统组件实现，避免重型依赖。
- 风格参考：[Apple HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Motion](https://developer.apple.com/design/human-interface-guidelines/motion)、[Search Fields](https://developer.apple.com/design/human-interface-guidelines/search-fields)、[Gestures](https://developer.apple.com/design/human-interface-guidelines/gestures)。
- 版权边界：只借鉴成熟开源应用的交互理念，不复制未知授权或 GPL 项目的 UI 素材、源码和图标。

## 4. 优先级与尽量复用的现状

**P0，体验正确/防丢数据：**
1. 修复 NoteDetail 分行间距与跨段选择；校准编辑器正文排版。
2. IME 开合、底部栏/悬浮控件稳定；键盘、系统返回、附件选择往返和旋转不丢草稿。
3. 条目左滑直接删除接入**现有** `App.kt` `moveToTrash` / `restore` / Snackbar，不再创建第二套删除状态。现有 `deletedAt` 与 30 天到期清理已有实现，重点验证多媒体引用和 Undo，而非重写回收站。

**P1，整体视觉与日常流畅：**
4. 记录/日记/详情/编辑/搜索统一视觉系统和间距；照片、音频密度随内容变化。
5. 周日期条与搜索过渡、阅读/图片浏览、少量符合人体工学的触感。
6. 视觉按浅/深色、320dp、系统 200% 字号验证，不只看 AI 生成概念图。

**P2，收尾与发布体验：**
7. 将用户可见 v0.24 安装包改为 `Jiyixia-v0.24-universal.apk`，不要再仅显示 `Jiaoban`。**不要修改** `cn.jiaoban` applicationId、旧数据路径或原签名证书。
8. 兼容 v0.23 老版更新器：当前 `scripts/publish_release.py` 的 `PREFIX`、`UpdateConfig.APK_PREFIX`、`publicApkUrl` 正则和公共 stable manifest 都要求 `Jiaoban-v...`。不能只改 ZIP/APK 名就发布。建议 v0.24 同一原签名 APK 同时保留 `Jiaoban-v0.24-universal.apk` 兼容附件和新名称附件（及对应校验/manifest），在 v0.24 更新器改认新命名；正式发布前通过 **v0.23 应用“检查更新”→ v0.24 保数据覆盖** 的真实链路。任何替代方案也必须先证明旧版更新兼容。

## 5. 验收：以真实体验为准

- 记录：首页进入编辑、连续写多段、键盘返回、选图片后回来、重启重新打开；内容、光标与附件不丢，IME 导航不跳。
- 阅读：普通换行、连续空行、旧清单文本、长文 200% 字号下段距自然，可跨行复制；滚动不卡。
- 删除：从列表中间左滑一次即可删除，无第二次点击；短滑回弹；连续多条/录音/照片/日记可撤销、可从回收站恢复；30 天清理与媒体引用安全。
- 搜索：文字/日期/现有类型筛选结果一致，离线可用；无结果用一句友好提示；退出保留首页位置。
- 日记：跳日/跳周、空日期、当天多条随记、图文、录音及旧数据正常。
- 录音：至少覆盖开始、暂停、锁屏、回应用、结束后保存与失败恢复；来源于用户入口的真实性能需 Android 设备验证。
- 视觉：真实 Compose 截图（非生图）目检浅/深、窄屏、200% 字号、图片/无图/空白/长文、键盘开关；玻璃层不能阻止点按或造成明显卡顿。
- 发布：v0.23 原证书升级、旧数据/媒体、公开下载/内置更新、正式 APK 名称、SHA-256 与新旧资源名兼容分别真实核对。没有 Android 真机实际跑过的步骤标记为 **未验证**，不可用编译成功替代。

## 6. 明确不做

- 不换包名/签名，不迁移数据库，不卸载清数据，不引入账户、广告、AI API、在线同步或巨大 UI 框架。
- 不为了“苹果感”大量增加无意义文案、虚构数据、动效或权限。
- 不复制 AI 概念图像素作为最终实现；真实截图与手势体验必须再审。
- **本文件仅设计交接**：新开发会话接续时按此规格与最新 GitHub 源码实施、验收、再按用户授权发布。
